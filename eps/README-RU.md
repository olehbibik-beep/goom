# GooM EPS — пожарная сигнализация

Готовая самостоятельная программа на общей базе PZTS. Проекты, автосохранение, меню, значки и права PROJECT отделены от PZTS/CCTV. Один аккаунт GooM работает во всех трёх редакторах.

## Куда загружать

На основной сайт: **содержимое этой папки целиком** в папку `eps/` репозитория `olehbibik-beep/goom`. Адрес программы: `https://goom.cz/eps/`.

Для отдельного репозитория `eps`: содержимое этой папки положить **прямо в корень** репозитория и включить GitHub Pages из `main` → `/ (root)`. Не вкладывайте ещё одну папку EPS. Файл `.nojekyll` и папку `vendor/` обязательно загрузить вместе с программой: там библиотека PDF. Своего CNAME для размещения на `goom.cz/eps/` не требуется.

Для единого входа рекомендуется адрес на общей доменной зоне `goom.cz/eps/`. При размещении на другом домене его потребуется добавить в разрешённые домены Firebase Authentication; сеанс браузера между разными доменами автоматически не переносится.

Открывать через HTTPS или локальный HTTP-сервер, а не двойным щелчком по index.html.

## Куда класть свои картинки

- `assets/devices/` — картинки пожарных устройств. Уже подготовлен 31 отдельный SVG.
- `assets/devices/manifest.json` — сопоставление типа устройства и имени файла. Для PNG/JPG поменяйте имя, например `"eps_smoke": "my-smoke.png"`. Имя без пробелов, только латиница, цифры, `_` и `-`; изображение до 2 МБ.
- `Hi.png` — ваша большая картинка при входе; `Intro.mp4` — вступительное видео.
- `assets/branding/welcome.svg` — запасная векторная картинка.
- `assets/branding/building-section.svg` — картинка здания в срезе этажей.
- `assets/branding/menu-mark.svg` и `menu-mark-active.svg` — картинки кнопки меню.
- `Logosite.png` — значок вкладки браузера. `Logo.png` / `Logo2.png` — общий бренд GooM.

Для чётких векторных значков используйте SVG `viewBox="0 0 48 48"` с простыми `circle`, `rect`, `line`, `polyline`, `polygon`, `text` без групп, скриптов и внешних ссылок. Они остаются векторами в SVG и DXF. PNG/JPG сохраняются в изображениях, PDF и SVG; в DXF используется встроенное векторное обозначение устройства. При ошибке файла остаётся встроенный значок — план продолжает работать. Картинку можно заменить без изменения кода; после загрузки обновите страницу.

## Устройства

Централь EPS; оптический дымовой, максимальный и дифференциальный тепловой, дым/тепло, CO-мультисенсорный, IR, UV и IR/UV пламени; передатчик, приёмник и отражатель линейного дымового; аспирационный, канальный дымовой и линейный тепловой; ручной пожарный; звуковой, световой, светозвуковой и речевой оповещатели; выносной индикатор; входной, выходной, комбинированный, релейный модули и изолятор; резервированное питание, выносная панель, магнит двери, управление клапаном и пожаротушением.

Обозначения — собственная схематическая графика GooM, а не заявление о соответствии конкретному стандарту. Расстановка и инженерная проверка выполняются проектировщиком; автоматические нормативные зоны пожарных извещателей не рассчитываются.

## Сохранение и доступ

Редактируемый проект `.TECH` содержит `application: "EPS"`. Есть PDF, SVG, DXF и печать; карты, фото на планшете и облако используют права PROJECT именно для EPS. На телефоне доступен просмотр и поиск облачных планов. Выдать PROJECT для EPS можно в существующей админке GooM. Публичная покупка тарифа EPS пока не подключена.

Исходная папка на компьютере: `C:\Users\Zelezo\Downloads\PZTS\EPS`.

В основной папке `goom-site/` уже подготовлены ссылки на EPS и выбор EPS в тарифах. Чтобы показать EPS на главной странице, загрузите также `index.html`, `main.js`, `styles.css`, `sitemap.xml` из `goom-site/` в корень репозитория `goom`, либо загрузите весь готовый архив сайта. При этом папка `eps/` должна лежать рядом с `pzts/` и `cctv/`.
