# GooM SK — сети и интернет

Самостоятельный редактор структурированной кабельной системы: 31 тип оборудования, медные и оптические точки, сетевые шкафы, Wi-Fi и клиенты. Проекты и права PROJECT отделены от PZTS, EPS и CCTV. Один аккаунт GooM работает на goom.cz.

## Папки

Программа: C:\Users\Zelezo\Downloads\PZTS\SK. Публикация: содержимое SK → папка sk/ репозитория olehbibik-beep/goom, адрес https://goom.cz/sk/. Загружайте .nojekyll и vendor вместе с программой.

Картинки устройств: assets/devices/. Уже есть отдельный SVG для каждого типа. PNG/JPG можно добавить через assets/devices/manifest.json (латинское имя без пробелов, до 2 МБ). Векторные SVG: viewBox="0 0 48 48", плоские circle, rect, line, polyline, polygon, text. PNG/JPG остаются растровыми; DXF использует встроенный векторный знак.

Картинки входа, здания, кнопки меню: assets/branding/. Для замены заставки также можно положить Hi.png и повторить сборку scripts/create-sk.cjs. Logosite.png — вкладка браузера, Logo2.png — знак GooM в меню.

## Работа

PDF/IMG/DXF, карты, этажи, адреса точек по группам, трассы, подписи и легенда. Сохранение .TECH с application: "SK", экспорт PDF/SVG/DXF и изображений. На телефоне — просмотр и поиск облачных проектов. Фото плана — планшет с PROJECT.

Голубые линии — обычные связи, янтарные — связи оптических компонентов, серые — питание. Цвет определяется типами концов линии; это схема, а не автоматическая сертификация канала или расчёт скорости, длины, PoE либо радиопокрытия. Номер обозначения — адрес на плане, не IP-адрес и не номер физического порта.

Права PROJECT выдаются в админке для SK. Публичная покупка подписки SK пока не подключена.
