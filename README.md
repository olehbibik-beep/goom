# GooM

Public home page for GooM, hosted on GitHub Pages at **https://goom.cz/**.

The page introduces the PZTS and CCTV editors, explains the workflow and PROJECT plans, and links to **support@goom.cz**. It supports Czech, English, German and Russian. The technical plan in the hero is an illustrative SVG with a PZTS/CCTV switch.

Buildless static files: `index.html`, `styles.css`, `main.js`, `Logo.png`, `robots.txt`, `sitemap.xml`. No package installation or build step is required. `.nojekyll` disables Jekyll processing. Preserve `CNAME` with `goom.cz`.

Editor links:

- PZTS: https://pzts.five.surf/
- CCTV: https://cctv.five.surf/

Prices shown here match the editor's published PROJECT pricing. Checkout and account management remain in PZTS; no payment or account credentials are collected by this home page. The contact link opens the visitor's mail application; it does not send mail automatically.

No analytics or external fonts are loaded. Only the chosen display language is stored locally in the browser.
